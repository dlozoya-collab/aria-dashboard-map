⏱ Time-Based Views — Requires a Weekly Snapshot Job

The Slack List gives only a current snapshot, so trend analytics (burndown velocity, cycle time, "what changed this week") require a weekly scheduled script to save a snapshot to Google Sheets. A GAS time trigger running every Sunday would unlock: weekly digest of what moved, cycle time per solution, slippage trend, and throughput rate over time. This is a one-time setup and feeds the Slack digest automatically.

Dashboard location: GAS web app (more flexibility, richer analytics, shareable link) vs. Slack-native (team already lives there, less setup).
